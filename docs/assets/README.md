# Documentation assets

The public visual set is deliberately small. Every retained terminal image is generated by
[`scripts/render-doc-assets.py`](../../scripts/render-doc-assets.py); there are no manual captures.

| File | Purpose | Source contract | Used in |
| --- | --- | --- | --- |
| `hero.gif` | Four-frame journey from pod initialization through governed execution and evidence | Current isolation golden plus the deterministic smoke workflow | Root README and docs index |
| `isolation.png` | Per-project workspace, codebase, session key, and scope | `tests/golden/cases/readonly/info_myshop.golden` | Root README |
| `governance.png` | Dispatch, approval pause/resume, active tool-call gate, and audit verification | Deterministic outcomes exercised by `scripts/smoke_workflow.py` | Root README |

The renderer uses the vendored `DejaVuSansMono.ttf` so glyphs and layout do not depend on host font
packages. Its redistribution terms are retained in `DejaVu-FONT-LICENSE.txt`. The font is a source
asset for the renderer, not another public screenshot.

## Regenerate and verify

Pillow is a declared development dependency, so the standard environment is sufficient:

```bash
uv sync --all-extras --dev
uv run python scripts/render-doc-assets.py
uv run python scripts/render-doc-assets.py --check
```

Each output embeds a SHA-256 render-contract fingerprint covering the renderer, vendored font,
owning CLI golden, and deterministic smoke source. `--check` verifies that fingerprint plus image
format, dimensions, animation frames, loop, and frame timing. This detects stale generated assets
without treating platform-specific PNG compression or font anti-aliasing as content drift. Public-
doc tests also fail for unreferenced media, extra PNG/GIF files, a missing renderer, or retired-brand
copy. A maintainer still visually inspects all three outputs when refreshing them.

## Visual rules

- Show current Docket commands and supported behavior; never invent a dashboard or hosted UI.
- Use anonymized project names and `~` paths. Never capture a real client, username, token, URL, or
  approval identifier.
- Lead with isolation, governed side effects, and inspectable evidence. Cost remains a labelled
  estimate, never the headline.
- Prefer one image with a clear product question over a collage of command output.
- Delete replaced assets instead of retaining an unreferenced screenshot “for later”; Git history
  is the archive.
