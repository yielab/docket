# Documentation assets

The public visual set is deliberately small. Every retained terminal image is generated by
[`scripts/render-doc-assets.py`](../../scripts/render-doc-assets.py) from the transcript of one
real run; there are no terminal screenshots and no invented output.

| File | Purpose | Captured scene | Used in |
| --- | --- | --- | --- |
| `hero.gif` | A diagram, not captured output: the four pod shapes `docket` ships (`build`, `respond`, `operate`, `routine`), with the roles and gates of `specs/functional/pod-blueprints.spec.md`. A task walks each shape, one reviewer sends work back for rework, one step waits for a person, and a strip under all four shows the audit log growing | none (drawn by the renderer) | Docs index |
| `isolation.png` | The Implementer's own workspace and git worktree, with `docket setup sandbox` showing isolation on (Landlock, network `none`) (the capture runs `docket setup sandbox on`); the operator's checkout holds only the exported team | `3-isolation` | Agent teams guide |
| `governance.png` | The policy dry-run asks for a high-risk push; the Lead parks a consultation first and the operator answers it with `task answer`; then the Implementer's `bash` call parks the task as `waiting_approval` under `high-risk-deploy`, the audit logs `tool.ask`, the trace records the denial with `executed: false`, and the audit chain verifies | `4-gate` | Security guide |

The renderer uses the vendored `DejaVuSansMono.ttf` so glyphs and layout do not depend on host font
packages. Its redistribution terms are retained in `DejaVu-FONT-LICENSE.txt`. The font is a source
asset for the renderer, not another public screenshot.

## Refresh the capture

[`scripts/maint/capture-doc-journey.sh`](../../scripts/maint/capture-doc-journey.sh) drives the
real CLI through every scene against a live OpenAI-compatible endpoint (default
`http://127.0.0.1:8081/v1`), under a throwaway `HOME`, and writes one transcript per scene with the
capture root rendered as `~`. It takes about five minutes because the gate scene waits out the
120-second approval timeout. A local model's output varies run to run, so copy what the new run
actually printed into the scene lists in the renderer: elide with `⋯`, never reword or invent a
line. The current scenes were captured on 2026-10-09 against a local 16k-context model. The `setup sandbox` lines of `isolation.png` were re-transcribed on 2026-10-13 from the real command on this host after bwrap was deleted (Landlock, network `none`). The CLI prints its plain voice (`ok`, `->`, `!`) when piped, which is what a transcript is, so the scenes show those prefixes. The local model may park a consultation before delegating; when it does, the capture is continued by answering it (`docket inbox`, `docket task answer <id> --option <id>`, `docket run`) in the same throwaway home, and the scene shows that round.

## Regenerate and verify

Pillow is a declared development dependency, so the standard environment is sufficient:

```bash
uv sync --all-extras --dev
uv run python scripts/render-doc-assets.py
uv run python scripts/render-doc-assets.py --check
```

Each output embeds a SHA-256 render-contract fingerprint covering the renderer, which holds the
transcribed scenes, and the vendored font. A scene too long for its frame fails the render instead
of being cut off. `--check` verifies that fingerprint plus image
format, dimensions, animation frames, loop, and frame timing. This detects stale generated assets
without treating platform-specific PNG compression or font anti-aliasing as content drift. Public-
doc tests also fail for unreferenced media, extra PNG/GIF files, a missing renderer, or retired-brand
copy. A maintainer still visually inspects all three outputs when refreshing them.

## Visual rules

- Show real output of current Docket commands, including failures the run produced; never invent
  a dashboard, a hosted UI, or a line the CLI did not print.
- Use anonymized project names and `~` paths. Never capture a real client, username, token, URL, or
  approval identifier.
- Lead with isolation, governed side effects, and inspectable evidence. Cost remains a labelled
  estimate, never the headline.
- Prefer one image with a clear product question over a collage of command output.
- Delete replaced assets instead of retaining an unreferenced screenshot “for later”; Git history
  is the archive.
