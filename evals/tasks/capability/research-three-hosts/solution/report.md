# PEP 557: Data Classes

PEP 557 added the `dataclasses` module and its `@dataclass` decorator to Python. The decorator
generates `__init__`, `__repr__` and comparison methods for a class from its annotated fields,
so a plain record type needs no boilerplate. It first shipped in Python 3.7.
